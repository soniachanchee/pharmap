# Pharmap — Project Specification

## 1. Project Overview

Pharmap is a medicine information and discovery platform designed initially for Mauritius, with the potential to expand globally.

The platform aims to make medicine-related information more accessible, organised and searchable.

## 2. Project Vision

To build a reliable and scalable platform that helps users discover medicines and access structured information about them.

## 3. Initial Scope

The first version will focus on:

- Medicine catalogue and identification
- Generic and brand-name medicine relationships
- Active ingredients
- Strengths and dosage forms
- Manufacturer information
- Medicine classification
- Search and filtering
- Country-specific medicine availability

## 4. Geographic Scope

Initial market: Mauritius.

Long-term ambition: International expansion through support for multiple countries and their respective medicine catalogues.

## 5. Technical Direction

- Database: PostgreSQL
- Version control: Git
- Repository hosting: GitHub
- Development environment: Visual Studio Code

## 6. Development Approach

Development will begin with database research, requirements analysis, entity-relationship modelling and relational database design before application development.

## 7. Important Considerations

- Data accuracy and traceability
- Reliable information sources
- Data normalisation
- Scalability across countries
- Clear distinction between medicine information and medical advice
